# JANUS R1 fork boundary

Terminal remains the owner-command and public ecosystem discovery surface.
Janus R1 supplies a separate metadata health verifier and an inert dependency /
organ proposal protocol. Its source and draft Registry pointers are recorded in
`config/JANUS_R1_ADMISSION_BINDING.json`; they do not grant an execution capability.

The former fork executor could create a fork and install two Habitat files from
metadata-level checks. It did not implement the complete commit, license-byte,
quarantine, independent review, bounded ledger and rollback gates named by its
historical contract. That historical contract remains preserved as source data.
The new code blocks every legacy mutation helper and non-GET transport before
an external effect, with `R1_EXECUTION_BINDING_REQUIRED`.

`--execute`, a token, a repository request's `policy_grant_id`, an asserted PASS,
and environment/configuration changes cannot enable an executor. The preview
never reads or sends `JANUS_FORK_TOKEN`. Its only network operation is a bounded,
credential-free GET of canonical public GitHub repository metadata. Unknown
source/rights remain held and no proposal claims source-byte or secret-scan
verification.

The existing public ecosystem observer and receipt branch are unchanged. The
legacy fork workflow was reversibly disabled on GitHub on 2026-11-23; its readback
was `disabled_manually`. This patch does not re-enable it. The replacement YAML
has read-only permissions, no secret binding, no fork execution, no source
writeback and short-lived diagnostic artifacts. A separate offline workflow
tests the hard barrier on the PR.

Rollback of this draft means withdrawing the PR or reverting its commit.
Restoring old execution is a separate deployment decision and must remain held
until a reviewed, authenticated executor satisfies the R1 requirements. A green
metadata report, successful contract CI or merge alone cannot authorize that
deployment. Actual forks, new repositories and working model changes remain
unavailable through this lane.
