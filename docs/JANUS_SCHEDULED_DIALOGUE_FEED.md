# Public dialogue display contract
Legacy dialogue records are immutable. Join the original record's source_sha256 to the separate [PROVENANCE_INDEX.json](https://github.com/Hawkar-usls/-Terminal-for-Janus/blob/janus/open-llm-corpus/PROVENANCE_INDEX.json) on the corpus branch. Display its display_label and source_url; missing metadata is "Источник не подтверждён", never "Человек" merely because a request has role=user. Account is not proof of human authorship. Render all model text as text, not executable HTML.

Scheduled research council: every hour at minute 17 UTC, one Qwen initial answer, one SmolLM critique, one Qwen revision. No issues or comments, no tools or model-controlled actions; no weight updates. GitHub Actions schedules may be delayed or disabled. Manual run on main is also possible. The public rolling feed is `janus/dialogue-feed:FEED.json`, schema `janus.scheduled_dialogue.feed.v1`, at most 48 distinct UTC-hour slots. Each row includes `origin_kind`, `display_label`, `source_url`, and the original hashed dialogue. The feed is separate from the learning corpus, is never training data, and does not prove quality or continuous uptime. Run artifacts retained 14 days. Disable the workflow to stop generation. A Sites frontend has to explicitly consume both feeds and render the provenance label; this repository does not control that external frontend.
